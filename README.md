# Routing Zhang — Personal Academic Website

A static academic website built with HTML, CSS, and JavaScript. No installation or build command is needed.

## Pages

- `index.html`: welcome screen with a moving keyword background, biography, research, contact, and friends.
- `becoming.html`: Behind the Paper: Growth & Gratitude collection.
- `purse-and-cradle-story.html`: reflection on The Purse and Cradle.
- `awe-to-wellness-story.html`: reflection on From Awe to Wellness.

Images, local fonts, and the two paper PDFs are included in `assets/`. Font licensing information is in `assets/fonts/OFL.txt`.

## GitHub Pages

Upload this folder's contents to the repository root, keeping `index.html` at the top level. In Settings → Pages, choose Deploy from a branch, then main and /(root). The `.nojekyll` file disables Jekyll processing.

No custom domain is configured in this package. Configure a domain in GitHub Pages after registering it.

When updating the website, keep any existing CNAME file created by GitHub Pages for your custom domain.
